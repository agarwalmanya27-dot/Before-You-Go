# Before You Go

A web-based travel management and planning system that helps users discover suitable destinations based on their vibe, mood, and travel preferences.

## Features
* Vibe and mood based destination selection
* Curated destination options based on user preferences
* Destination exploration
* Information about places to visit
* Famous food recommendations
* Shopping information

## Technologies Used
* HTML
* CSS
* JavaScript
* Python
* SQL

## Future Enhancements
* Weather integration
* Budget planning
* Map integration
* Expansion of destination and travel information
